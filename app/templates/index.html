軟體工程新手筆記：架構與實踐

1. 規格先行 (SDD)：先撰寫詳細的 SPEC.md，定義清楚驗收準則（Acceptance Criteria）與 Non-goals，再讓 AI 產出實作。

2. 測試驅動 (TDD)：核心業務邏輯 engine.py 與 API 路由皆具備完整單元測試，透過 python -m unittest 驗證正確性。

3. 零手寫 JS、零 npm 與現代圖標：利用 HTMX 宣告式屬性（hx-post、hx-target、hx-swap）進行局部 DOM 替換，搭配 Lucide Icons CDN 呈現專業質感，保持程式碼純淨與極簡依賴。
